Datenschutz und technische Hinweise

Stand: 1. Oktober 2026

Private Nutzung

Pumperella ist ein kleines, nichtkommerzielles Kegelspiel. Es enthält keine Werbung, keine Webanalyse und kein Nutzertracking.

Hosting über GitHub Pages

Die statische Website wird über GitHub Pages bereitgestellt. GitHub dokumentiert, dass beim Besuch einer GitHub-Pages-Seite die IP-Adresse des Besuchers zu Sicherheitszwecken protokolliert und gespeichert wird. Weitere Informationen stehen in der GitHub-Pages-Dokumentation und der dort verlinkten GitHub-Datenschutzerklärung.

Keine externen Runtime-CDNs

Die für das Spiel benötigten JavaScript-Bibliotheken werden direkt von dieser Website ausgeliefert. Beim normalen Spielstart werden dafür keine Ressourcen von jsDelivr, Google Fonts oder vergleichbaren Drittanbieter-CDNs geladen.

Lokaler Spielfortschritt

Das Spiel speichert auf dem verwendeten Gerät ausschließlich die Ziehungs-ID und die Anzahl bereits aufgedeckter Termine in localStorage bzw. ersatzweise sessionStorage. Diese Daten dienen nur dazu, den Spielfortschritt nach einem Neuladen wiederherzustellen. Der Spielername und die Termine werden dort nicht gespeichert. Ist Browser-Speicher deaktiviert, bleibt das Spiel nutzbar, der Fortschritt kann nach einem Neuladen jedoch verloren gehen.

Persönlicher Spiellink

Der persönliche Spiellink enthält im URL-Fragment nach dem #-Zeichen einen digital signierten Spielcode mit Ziehungs-ID, Spielername und Terminen. Dieser Code ist signiert, aber nicht verschlüsselt. Personen, die den vollständigen Link erhalten, können die enthaltenen Angaben technisch auslesen. Der Link sollte deshalb nur an die vorgesehene Person weitergegeben werden.

URL-Fragmente werden bei üblichen HTTP-Anfragen nicht als Bestandteil der Request-URL an den Webserver übertragen.

Software und Lizenzen

Der projektspezifische Quellcode ist öffentlich einsehbar, aber nicht unter einer Open-Source-Lizenz freigegeben. Drittanbieter-Komponenten bleiben unter ihren jeweiligen MIT-Lizenzen. Die vollständigen Runtime-Lizenztexte liegen unter Three.js und cannon-es.
