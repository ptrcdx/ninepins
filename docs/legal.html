Datenschutz und technische Hinweise

Stand: 1. Oktober 2026

Verantwortliche Stelle

Noch nicht festgelegt.

Dies ist eine vorläufige Angabe. Für eine Nutzung, bei der die Datenschutz-Grundverordnung anwendbar ist, muss vor einer entsprechenden Veröffentlichung eine tatsächlich verantwortliche Person oder Stelle mit geeigneten Kontaktdaten benannt werden.

Zweck des Angebots

Pumperella ist ein kleines, nichtkommerzielles Kegelspiel für einen begrenzten Personenkreis. Es enthält keine Werbung, keine Webanalyse und kein Nutzertracking. Personenbezogene Angaben im persönlichen Spielcode werden ausschließlich verwendet, um die zugewiesenen Termine im Browser anzuzeigen und die Integrität des Spielcodes zu prüfen.

Hosting über GitHub Pages

Die statische Website wird über GitHub Pages bereitgestellt. GitHub dokumentiert, dass beim Besuch einer GitHub-Pages-Seite die IP-Adresse des Besuchers zu Sicherheitszwecken protokolliert und gespeichert wird. GitHub kann Daten nach Maßgabe der eigenen Datenschutzinformationen auch außerhalb des Europäischen Wirtschaftsraums verarbeiten.

Empfänger der für Hosting und Auslieferung technisch erforderlichen Daten ist GitHub als Hostinganbieter. Maßgeblich sind die GitHub-Pages-Dokumentation und das GitHub General Privacy Statement.

Rechtsgrundlagen

Soweit die DSGVO anwendbar ist, wird der Betrieb und die technische Absicherung des nichtkommerziellen Angebots auf das berechtigte Interesse an der Bereitstellung und sicheren Auslieferung des Spiels gestützt (Art. 6 Abs. 1 lit. f DSGVO). Die dauerhafte Speicherung des Spielfortschritts auf dem Endgerät erfolgt nur nach einer ausdrücklichen Auswahl durch die spielende Person. Diese Auswahl kann jederzeit im Spiel widerrufen werden.

Keine externen Runtime-CDNs

Die für das Spiel benötigten JavaScript-Bibliotheken werden direkt von dieser Website ausgeliefert. Beim normalen Spielstart werden dafür keine Ressourcen von jsDelivr, Google Fonts oder vergleichbaren Drittanbieter-CDNs geladen.

Lokaler Spielfortschritt

Beim ersten gültigen Spielaufruf wird gefragt, ob der Spielfortschritt auf diesem Gerät gespeichert werden soll. Die getroffene Auswahl wird als technische Präferenz in localStorage gespeichert, damit der Hinweis bei späteren Aufrufen nicht erneut angezeigt werden muss.

Nur bei Zustimmung speichert die Anwendung zusätzlich die Ziehungs-ID und die Anzahl bereits aufgedeckter Termine in localStorage. Spielername und Termine werden nicht als Fortschrittsdaten gespeichert. Wird die Speicherung später deaktiviert, werden keine weiteren Fortschrittsänderungen dauerhaft geschrieben; bereits gespeicherter Fortschritt bleibt zunächst erhalten. Er kann über das Menü im Spiel ausdrücklich gelöscht werden. Browserdaten können zusätzlich jederzeit über die Browsereinstellungen gelöscht werden.

Persönlicher Spiellink

Der persönliche Spiellink enthält im URL-Fragment nach dem #-Zeichen einen digital signierten Spielcode mit Ziehungs-ID, Spielername und Terminen. Dieser Code ist signiert, aber nicht verschlüsselt. Personen, die den vollständigen Link erhalten, können die enthaltenen Angaben technisch auslesen. Der Link sollte deshalb nur an die vorgesehene Person weitergegeben werden.

URL-Fragmente werden bei üblichen HTTP-Anfragen nicht als Bestandteil der Request-URL an den Webserver übertragen.

Speicherdauer

Lokal gespeicherter Spielfortschritt bleibt bis zur ausdrücklichen Löschung im Spiel, bis zur Löschung der Browserdaten oder bis zur manuellen Entfernung durch den Browser erhalten. Die gespeicherte Auswahl zur Fortschrittsspeicherung bleibt bis zu einer Änderung der Einstellung oder bis zur Löschung der Browserdaten erhalten. Für Server- und Sicherheitsprotokolle von GitHub gelten die von GitHub festgelegten Aufbewahrungsfristen; diese werden von Pumperella nicht gesteuert.

Betroffenenrechte

Soweit die DSGVO anwendbar ist, bestehen nach den gesetzlichen Voraussetzungen insbesondere Rechte auf Auskunft, Berichtigung, Löschung, Einschränkung der Verarbeitung und Widerspruch. Eine erteilte Einwilligung kann für die Zukunft widerrufen werden. Außerdem besteht das Recht, sich bei einer zuständigen Datenschutzaufsichtsbehörde zu beschweren.

Automatisierte Entscheidungen

Es findet keine automatisierte Entscheidungsfindung im Sinne von Art. 22 DSGVO statt. Die zufällige Terminziehung ist eine Spielfunktion und dient keiner Bewertung oder Profilbildung.
