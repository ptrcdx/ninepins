# Publication checklist

Before changing this repository from private to public:

- [ ] Replace historical personal Git commit email addresses with a GitHub
      `noreply` address, or consciously accept that the historical addresses
      will become public.
- [ ] Configure future Git commits to use the GitHub `noreply` address.
- [ ] Enable GitHub's email privacy / push-protection setting where available.
- [ ] Confirm that no exported private signing key or draw archive is tracked.
- [ ] Confirm that `docs/legal.html` contains a real responsible party if the
      GDPR applies to the intended publication.
- [ ] Confirm GitHub Pages serves the expected `docs/` content.

The current placeholder "Noch nicht festgelegt" in the privacy notice is
deliberately not a fictitious identity. It must be replaced if a legally valid
responsible-party disclosure is required.
