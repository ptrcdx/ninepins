# Contributing

This repository is source-visible but **not open source**.

External pull requests, code contributions, assets, translations, or other
submissions are not requested and should not be submitted unless they have
been agreed with the project maintainers in advance.

Do not submit:

- code or assets copied from third parties without documented permission,
- private signing keys, draw archives, personal game links, or other secrets,
- personal data that is not necessary for the project.

The licenses of third-party components listed in
`THIRD_PARTY_NOTICES.md` remain unaffected by this policy.

Opening an issue for a technical defect does not grant any license to the
project-specific source code.
